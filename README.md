## 📌 About This Repository

This repository contains my **practical implementation and study of Statistics for Data Science and Machine Learning**.

The purpose of this repository is to go beyond simply memorizing statistical formulas. I focused on understanding:

* 📖 **What** a statistical concept means
* 🧠 **Why** it works
* 📐 **How** it is calculated
* 🧪 **When** it should be used
* 🐍 **How to implement it using Python**
* 📊 **How to visualize and interpret the results**

The repository progresses from **fundamental statistical concepts** to more advanced topics such as **probability, random variables, probability distributions, sampling, hypothesis testing, ANOVA, MANOVA, correlation, and practical statistical analysis**.
